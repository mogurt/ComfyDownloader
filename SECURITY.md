# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by emailing `mcyogurtg@gmail.com`.

Include:

- A clear description of the issue
- Steps to reproduce
- Affected versions or commit range, if known
- Any proof-of-concept or logs that help explain impact

Please avoid opening a public GitHub issue for security-sensitive reports.

## Supported Versions

Security fixes are provided on a best-effort basis for the latest development branch and the most recent release.
